Tiwut's Windows Repair Tool

About the Tool 🛠️

The **Windows Repair Tool** is a simple, Python-based graphical user interface (GUI) application designed to execute essential Windows system integrity and repair commands: **System File Checker (SFC)** and **Deployment Image Servicing and Management (DISM)**.

⚠️ **Requirement:** The application requires **administrative privileges** to run the system commands effectively, which is automatically handled by the included script logic.

The GUI provides live output, progress tracking, and estimated time remaining for long-running commands.

Key Features 🚀

  • **System File Checker (`sfc /scannow`):** Scans and replaces corrupted or missing system files.
  • **DISM ScanHealth:** Checks the health of the Windows component store to detect corruption.
  • **DISM RestoreHealth:** Repairs the Windows component store using online resources.
  • **Graphical Interface (Tkinter):** User-friendly interface with progress and status updates.
  • **Asynchronous Execution:** Commands run in a background thread, keeping the GUI responsive.
  • **Admin Elevation:** Automatically requests administrator rights upon execution.

Commands Explained 💻

The tool simplifies the execution of these powerful repair commands:

  • **Run System File Checker:** Executes sfc /scannow.
  • **Check Windows Image Health:** Executes DISM /Online /Cleanup-Image /ScanHealth. This command typically runs relatively quickly to report the image status.
  • **Restore Windows Image Health:** Executes DISM /Online /Cleanup-Image /RestoreHealth. This command is used to fix any corruption found and can take a significant amount of time.
